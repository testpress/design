1. Scoring Method

  • Raw Score: Converts the number of correct answers into a scaled score.
  • Percentage: Converts the percentage of correct answers into a scaled score.

2. How Mappings Work

  • Each row starts at a raw-score cutoff.
  • The cutoff applies from that score up to the score before the next cutoff.
  • The range end is calculated automatically and cannot be edited.
  • Only the starting raw-score cutoff and scaled score values are configured.
Example: 0 → 200
3 → 250
6 → 300
This becomes: 0 – 2 → 200
3 – 5 → 250
6+ → 300

3. Different Section Lengths

  • Mappings are shared across sections.
  • Different sections can have different maximum raw scores.
  • A configuration can contain mappings for higher raw scores than a particular section allows.
  • For example, if one section has 22 questions, mappings above 22 are not used for that section. Another section with more questions can use those mappings.

4. Adding or Removing Mappings

  • Use the row actions menu to Insert Above or Insert Below.
  • When a new row is added, enter its raw-score cutoff and scaled score.
  • The surrounding ranges automatically recalculate.
  • Cutoffs must be unique and in ascending order.

5. Importing a Spreadsheet

  • Use Import Spreadsheet to add or update mappings in bulk.
  • Download the sample template, enter the raw-score cutoff and scaled-score values, then upload the completed .xlsx file.
  • The spreadsheet uses cutoff values, not ranges.
  • The UI automatically calculates and displays the ranges.
  • Spreadsheet imports run as a background task. While an import is processing, this configuration is temporarily locked to prevent conflicting edits.

6. Saving Changes

  • Changes are not applied until Save Changes is clicked.
  • Manual edits, inserted rows, deleted rows, and imported mappings are saved when the configuration is saved.
