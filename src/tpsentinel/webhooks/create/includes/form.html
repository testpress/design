When you save

  1. New events follow the new settings

    Events and workspaces you add or remove apply from the next event.

  2. Waiting deliveries go to the new address

    If you change the endpoint, deliveries not yet sent go there, with the same content.

  3. The signing secret stays the same

    Your system keeps checking requests with the secret it already has.

{% else %}

How it works

  1. Sends events as they happen

    When one of your chosen events happens, TPSentinel sends its details to your endpoint right away.

  2. Signs every request

    After you add the webhook, you get a signing secret. It's shown only once, so save it.

  3. Your system checks it

    Your developer uses the secret to confirm each request came from TPSentinel.
