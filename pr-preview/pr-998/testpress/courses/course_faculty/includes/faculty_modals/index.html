How it works

  1. Add the teachers of this course

  2. Students see them before buying

    Before buying this course, students see each teacher's photo, subjects, introduction, highlights, qualifications and intro video.

  3. Fill a teacher's details once

    If a teacher takes more than one course, their photo and details are the same everywhere. Only the subjects and video are different for each course.
