How Scaled Score Conversion Works

What is scaled score conversion?

Scaled score conversion defines how a student's raw score or percentage is converted into the final scaled score shown for a section.

How does it work?

Each mapping starts at a raw-score cutoff and applies until the score before the next cutoff. Only the starting cutoff is entered. The end of each range is calculated automatically.

Example: 0 → 200
3 → 250
6 → 300
This becomes: 0 – 2 → 200
3 – 5 → 250
6+ → 300

How do I configure it?

Add a row for each cutoff and enter the corresponding scaled score. You can insert, edit, or delete mappings using the row actions. You can also import the mappings using the sample spreadsheet.

What about different sections?

The configuration can contain mappings for sections with different maximum raw scores. If a section has 22 questions, scores above 22 cannot occur in that section, so those higher mappings are simply not used. Another section with more questions can use them.

How does import work?

Download the sample spreadsheet, enter the required cutoff and scaled score values, and upload it to update the mappings in bulk. The imported mappings replace the existing mappings once the import is completed. The configuration is temporarily locked while the import is processing.
