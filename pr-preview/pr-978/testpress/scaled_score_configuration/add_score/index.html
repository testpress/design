How it works

  • Define the score students should see in their exam results.
  • Choose the exam sections or modules that contribute to that score.
  • Decide whether those sections produce one score or separate scores.
  • Convert the exam results into the student score using a score mapping.
  • If there are multiple scores, combine them by adding or averaging them.
